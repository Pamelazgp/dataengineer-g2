## Entornos virtuales
### Creat entorno virtual
``` bash
python -m venv 'nombre_del_entorno'
```
### Activar el entorno virtual

``` bash
#Windows CMD/Powershell
nombre_del_entorno\Scripts\activate
# MacOs/Linux
source nombre_del_entorno/bin/activate
```
